# Smart Shop AI Assistant

**Smart Shopping Assistant** — A WordPress and WooCommerce plugin that helps customers find products through natural language chat.

This plugin displays a floating chat widget on your store. Customers can describe what they need in plain language — for example, "I need 16 inch wheels for Peugeot 206" — and the assistant uses AI to detect intent, search related products in WooCommerce, rank the results, and display them in the chat.

---

## What does this project do?

1. **Multi-turn conversation** — Customers can explain their needs across several messages; the assistant keeps conversation context.
2. **Intent detection** — User messages are analyzed with AI to determine the product type (wheels, battery, tires, etc.) and desired attributes (vehicle, size, color, brand).
3. **Smart search** — Natural language requests are converted into structured WooCommerce filters (global attributes like `pa_vehicle`, `pa_wheel-size`).
4. **Normal search** — If the user provides an exact product name, standard WooCommerce text search is used as a fallback.
5. **Product ranking** — Results are scored and sorted by vehicle match, size, color, brand, product type, and stock availability.
6. **AI responses** — Final replies are generated by the selected language model; price and stock are read only from real WooCommerce data.
7. **Full admin panel** — Configure AI provider, rules, system prompt, chatbot appearance, logs, and diagnostics.

## Features

### Chatbot & UX

| Feature | Description |
|--------|-------------|
| Floating chat widget | Corner button with configurable animation and position |
| Appearance customization | Title, avatar emoji, colors, border radius, font size |
| Welcome message | Editable welcome text (English by default) |
| Quick actions | Shortcuts like "Find wheels", "Find a battery", "Find tires" |
| Add to cart | Add products to cart from chat (can be enabled/disabled) |

### AI

| Feature | Description |
|--------|-------------|
| Multiple providers | OpenAI, Anthropic (Claude), Google Gemini, OpenAI-compatible |
| Compatible services | OpenRouter, Groq, Together AI, DeepSeek, Mistral, Perplexity, and more |
| Model settings | Model selection, temperature, max tokens, timeout |
| System prompt | Editable global prompt to control assistant behavior |
| AI rules | Priority-based rules with active/inactive status (e.g. ask for wheel size, filter stock) |

### Search & Products

| Feature | Description |
|--------|-------------|
| Smart search | Convert natural language to WooCommerce attributes |
| Normal search | Text-based product search |
| Auto attribute discovery | Detect WooCommerce global attributes and map them |
| Ranking | Match score based on vehicle (30%), size (25%), color (15%), brand (15%), product type (10%), stock (5%) |
| MCP | Direct WooCommerce connection or external WooCommerce MCP service |

### AI Capabilities

You can control what the assistant is allowed to do:

- Search products
- Search by attributes
- Get product details
- Check stock
- Check price
- Add to cart
- Recommend products
- Ask follow-up questions
- Compare products

### Management & Diagnostics

| Feature | Description |
|--------|-------------|
| Conversation logs | Store intent, search query, found products, and response time |
| System health checks | Verify AI, MCP, WooCommerce, and attribute mapping |
| Test runner | Send a test query from the admin panel |
| Security | REST nonce, admin capability checks, masked API keys |

## Installation

1. Copy the `smart-shop-ai` folder to `wp-content/plugins/`.
2. Activate the plugin from **Plugins** in the WordPress admin.
3. Open **Smart Shop AI** from the admin menu.
4. Configure your AI provider (API key and model).
5. Map WooCommerce attributes (vehicle, wheel size, color, etc.).
6. Review AI rules and the system prompt.
7. Run checks from **Diagnostics**.

---

## Quick Start

| Step | Action |
|------|--------|
| 1. AI Provider | Set API key and model (e.g. `gpt-4o-mini`) |
| 2. MCP Settings | Keep default "WooCommerce Direct" or connect an external MCP |

| 4. AI Rules | Review default rules (ask for size, filter stock, etc.) |

## Architecture

```
smart-shop-ai/
├── smart-shop-ai.php          # Plugin entry point
├── includes/
│   ├── Core/                  # Plugin, Settings, Logger, Activator
│   ├── AI/                    # AI providers, AIService, IntentParser
│   ├── MCP/                   # MCP providers, MCPService
│   ├── WooCommerce/           # AttributeDiscovery, ProductSearcher
│   ├── Search/                # SmartSearch, NormalSearch, SearchRouter
│   ├── Recommendation/        # ProductRanker
│   ├── Rules/                 # RulesManager
│   ├── REST/                  # Chat, Settings, Diagnostics
│   ├── Admin/                 # Admin menu
│   └── Frontend/              # Chatbot loader
├── admin/                     # Admin CSS/JS
├── frontend/                  # Chatbot CSS/JS
└── templates/                 # Admin and frontend templates
```

### Message Processing Flow

```
User message
    ↓
Intent extraction (AI + IntentParser)
    ↓
Search routing (SearchRouter)
    ├── Smart search (by attributes)
    └── Normal search (by text)
    ↓
Fetch products from WooCommerce (MCP)
    ↓
Ranking (ProductRanker)
    ↓
Generate final response (AI)
    ↓
Display in chatbot + log conversation
```
